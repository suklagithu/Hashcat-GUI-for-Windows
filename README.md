# Hashcat GUI for Windows

A graphical user interface for Hashcat built with Python and PyQt5.

## Features

- Simple graphical interface for Hashcat
- Hash mode selection
- Wordlist selection
- Automatic hash mode detection
- Hashcat output and status display
- Password recovery progress monitoring
- Case-based output organization
- Supports CPU and GPU-based Hashcat workloads

## Requirements

- Windows
- Python 3.x
- PyQt5
- Hashcat
